# 🤖 AI Gesture Recognition Game

An AI-based hand gesture recognition project developed using Python, Computer Vision, and Streamlit.

The application detects hand gestures from uploaded images and performs game-related actions based on the detected gesture.

---

# 📌 Features

- Detects hand gestures using AI
- Uses Computer Vision techniques
- Upload hand images for recognition
- Detects:
  - Open Palm
  - Fist
  - One Finger
  - Two Fingers
  - Thumbs Up
- Displays gesture-based game actions
- User-friendly Streamlit interface

---

# 🧠 AI Concepts Used

## Computer Vision
The system processes hand images using OpenCV.

## Hand Landmark Detection
MediaPipe detects hand landmarks and finger positions.

## Gesture Recognition
The application identifies gestures based on finger patterns.

## Decision Making
The system maps gestures to game actions.
